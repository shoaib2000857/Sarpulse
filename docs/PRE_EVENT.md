# Pre-event preparation checklist

**Status:** Collaboration setup only; actual SARPulse solution development is scheduled for the official NASA Space Apps hackathon window.

- [ ] Read the official [Dancing with the SARs](https://www.spaceappschallenge.org/2026/challenges/dancing-with-the-sars/) challenge statement and Resources tab.
- [ ] Review latest 2026 participant guidelines and any local event instructions.
- [ ] Join/confirm StarFire team membership.
- [ ] Review scientific background: NISAR GCOV, HH/HV polarizations, calibrated backscatter and georeferencing.
- [ ] Confirm access to NASA Earthdata and ASF Vertex.
- [ ] Identify candidate areas and the evidence that would be required to prove change.
- [ ] Learn where to find product documentation and how to determine acquisition comparability.
- [ ] Confirm which person owns each subsystem and how interfaces will be agreed.
- [ ] Confirm repository access, branching and how to open PRs.
- [ ] Set up personal development environments without writing challenge-specific solution code.
- [ ] Verify final submission, code reuse and AI-disclosure rules when current guidance becomes available.

## Build-window go/no-go
The team should not assert a finished change-detection story until two or more comparable real NISAR scenes and a scientifically defensible baseline are available. If Brahmaputra does not have the needed acquisitions, select another region with verified data.
