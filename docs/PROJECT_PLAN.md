# SARPulse — execution overview

**Team:** StarFire. **Challenge:** NASA Space Apps 2026 — Dancing with the SARs.

This is a preparation-level summary of the team's longer research master plan, not code or a claim of completed scientific work.

## Mission
Build an accessible, explainable platform that lets users inspect NISAR-derived change across a floodplain or wetland over time. Interpret change using radar physics, complementary data and explicit evidence.

## Study area
The Brahmaputra floodplain is the primary **candidate**, not a verified final selection. Confirm compatible multi-date NISAR L-band coverage first. Nagapattinam or another verified area may replace it.

## Essential demo (P0)
1. Retrieve and validate genuine NISAR scene metadata and comparable acquisitions.
2. Generate aligned analysis-ready radar bands.
3. Create and evaluate a defensible open-water change baseline.
4. Show actual dated acquisitions and change overlays in a responsive web map.
5. Display source lineage, polarization and processing details.
6. Document limitations and at least one independent science check.

## Enhancements if time permits (P1)
- Multi-polarization scattering features
- GPM rainfall and cloud-free optical imagery context
- Interactive Science Lab, transparency on errors and uncertainties
- Guided story, polished UX, downloadable provenance

## Deferred (P2)
- General on-demand global computation
- Broad set of change classes
- Large foundation models or ungrounded AI narrators
- Multi-frequency analysis without verified paired inputs

## Definition of success
A public, working demo of **one** authentic and reproducible SAR-based environmental investigation, with scientific evidence and an accessible explanation. Do not invent performance figures or claim the whole planet is covered.
