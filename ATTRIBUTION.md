# Attribution

SARPulse is an independent Team StarFire project, not an official NASA/ISRO product or an endorsed operational service. Team contributions: Shoaib (platform/integration), Veer (ingestion), Naveen (analysis and ingestion collaboration), Shridhar (API/context), Nidhi (frontend) and Hansika (UX/presentation). Final completion status is tracked separately; ownership alone does not imply delivery.

NASA/JPL-Caltech NISAR and ASF DAAC provide the primary observational archive and documentation. NASA Earthdata/NSIDC's earthaccess library supports access. Other data attribution and limitations are in `DATA_SOURCES.md`; each final run retains its own input provenance.

The software uses Python, NumPy, SciPy, h5py, Rasterio/GDAL, pyproj/PROJ, scikit-learn, Requests, earthaccess and their dependencies; FastAPI, Starlette, Pydantic, Uvicorn; pytest and HTTPX for tests; uv for dependency management; Git/GitHub for source control and CI. Exact dependency versions are in `requirements.lock.txt`. Their own licenses apply to their code. This repository's license covers original Team StarFire code, not third-party data, libraries or branding.

The baseline follows Otsu histogram thresholding and an implementation of split-based selection of bimodal radar tiles. It is not a certified reproduction of a published flood-mapping product. Gaussian-mixture comparison is internal consistency, not external validation. Method descriptions are in the science module READMEs.

OpenAI Codex assisted integration code and text; see `AI_DISCLOSURE.md`. Confirm and append other teammate SI tools and external sources before submission. No new raster illustrations, audio or video were generated by this integration work.
